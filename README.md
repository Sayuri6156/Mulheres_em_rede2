# Mulheres em Rede

Protótipo acadêmico com quatro páginas: Início, Guia Acadêmico, Vagas e Oportunidades e Apoio às Mulheres.

## Publicação no GitHub Pages

1. Crie um repositório no GitHub, por exemplo `mulheres-em-rede`.
2. Extraia este ZIP e envie os arquivos e a pasta assets para a raiz do repositório. O index.html deve ficar diretamente na raiz.
3. Confirme o envio com Commit changes.
4. Abra Settings > Pages.
5. Em Build and deployment, selecione Deploy from a branch.
6. Selecione a branch main e a pasta / (root). Salve.
7. Aguarde a publicação e use o endereço exibido pelo GitHub Pages.

O ZIP não deve ser enviado como um único arquivo: envie seu conteúdo extraído, preservando a pasta assets.

## Funcionamento

Site estático em HTML, CSS e JavaScript. Não precisa instalar dependências, compilar ou configurar servidor. Os arquivos de mídia são locais. A navegação utiliza fragmentos de URL (#inicio, #guia, #vagas e #apoio).

As vagas são fictícias e servem para demonstrar a busca e os filtros. Não há integração automática com portais de vagas nem coleta de candidaturas. Os links de projetos e serviços levam a fontes externas da UFPR. O projeto é independente, sem vínculo oficial com a instituição.

## Arquivos

- index.html: estrutura principal
- style.css: identidade visual e layout responsivo
- app.js: conteúdo e interações
- assets/: ilustração, vídeo, imagem de capa e legendas

O vídeo de apresentação tem texto na tela, legendas e transcrição disponível na página inicial.
